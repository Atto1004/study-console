## 1. 화풍 — 추천: 「오버워치풍 2D」로 통일

### 오버워치 같은 실시간 3D가 어려운 이유
| 필요한 것 | 지금 가능한가 |
|---|---|
| 오버워치 질감의 캐릭터 3D 모델 | 힉스필드 3D 생성으로 형태는 나온다. 질감과 관절은 손봐야 한다 |
| 뼈대(리그)와 팔 동작 | 몸은 자동 리깅으로 된다. 손가락과 자연스러운 몸짓은 수작업이다 |
| 표정(얼굴 변형) | 3D 아티스트가 할 일이다. **지금 도구로는 못 한다** |
| 웹에서 3명 동시 렌더 | 되지만 아이패드에서 렉이 걸릴 수 있다 |

→ 시험 전에는 불가능하다. 시험 뒤에도 몇 주가 걸리고 품질을 장담할 수 없다.

### 대신 할 것: 오버워치풍 2D 일러스트 + 짧은 움직임 영상
- **그림**: 오버워치 히어로 일러스트처럼 3D로 렌더한 듯한 매끈한 스타일. 비율은 과장하고, 색은 선명하게, 빛은 부드럽게. 사진 같은 실사도, 도트·저폴리도 아니다.
- **움직임**: 상태별 2~4초짜리 반복 영상을 힉스필드로 만든다. 숨쉬기, 말하기(팔 제스처), 타자, 생각, 손 흔들기. 배경은 투명하게 잘라 자리에 얹는다 → 팔이 자연스럽게 움직이고 표정도 바뀐다.
- **표정**: 정지 그림 6종(기본·미소·웃음·생각·진지·놀람)을 영상 사이사이에 겹쳐 바꾼다.
- **공간·가구**: 캐릭터와 같은 오버워치풍 일러스트로 그린다.
- **3D 걷어내기**: 학교 1인칭 걷기와 대표실 3D 비서를 없앤다. 이동은 2절의 2D 방식으로 한다.

## 2. 하나로 이어진 세계 — 지도
```
[대표실]  ─문─  [엘리베이터 홀]  ─이동─  [학교 1층 복도(로비)]
   │                                      ├─ 교실 5곳(정역학·미적2·공수1·일물2·CADD)
   │                                      ├─ 자료실
   │                                      ├─ 과제실
   └─ 비서 자리 3(아톰·오타·토토)          └─ 상담실(스앵님 1:1)
```
- **이동 방식(추천: 장면 전환형)**: 공간 하나가 가로로 넓은 일러스트 한 장면이다. 문이나 화살표를 누르면 걸어가는 짧은 전환(화면이 옆으로 밀리고 발소리)을 거쳐 다음 장면으로 간다. 쯔꾸르처럼 타일 위를 걷지는 않지만 한 건물을 돌아다니는 느낌을 낸다.
- **공통 HUD**: 어느 화면에서나 같다.
  - 위: 한도 게이지, 시계, 지금 위치
  - 오른쪽 위: 지도 아이콘(전체 지도에서 바로 이동)
  - 아래: 대화창(누구와든)
- **캐릭터가 공간을 오간다**: 비서가 학교 복도까지 따라와 말을 건다(예: 오타 「이 과제 마감 내일이에요」). 스앵님은 시험 D-3에 대표실로 찾아온다.
- **시간대**: 장면마다 실제 시각에 따라 아침·낮·저녁·밤으로 바뀐다. 대표실에는 이미 있다.

## 4. 수업 — 「강의 먼저, 질문은 그다음」
지금은 단계 정리 1~2줄을 읽고 바로 질문한다. 이렇게 바꾼다.
1. **진짜 강의 대본**: 단계마다 스앵님이 1~3분 설명하는 대본을 만든다. 근거는 수업 정리본·교재·판서이고, 미리 생성해 캐시해 둔다.
   - 대본 구성: 오늘 왜 배우나 → 핵심 개념(쉬운 말로) → 칠판 판서 단계별 → 예제 하나 풀이 → 흔한 실수 → 「이제 확인해 볼게요」
2. **강의가 끝나야 질문**: 질문 칸은 강의가 끝날 때까지 잠근다. 건너뛰기(⏭)는 되지만 「강의를 건너뛰었어요」라고 표시한다.
3. **질문도 강의 내용에서**: 방금 설명한 예제를 살짝 바꾼 문제부터 낸다.
4. **도중 질문**: 강의 중에 「?」로 끼어들어 물어볼 수 있다(지금 기능 유지).
5. **검수**: 대본은 내용 정확성이 걸린 일이라 오타 검수를 거친다.

※ 오타 팀이 지금 학습앱 main 에서 교실 화면(판서·풀이 나란히)을 고치는 중이다. 겹치지 않게 역할을 나눠야 한다.

## 7. 지금 상태 진단 (캡처 기준)
- **스쿨 메인(로비)**: 복도 그림 위에 과목 카드 7개가 격자로 떠 있다. 카드에는 「n회 수업 · n개 개념」만 있다. 「어디서 시작할지, 함께 정해봐요」 문구와 상담실 버튼, 아래 「학습 이어가기·복습할 것」이 전부다. 공간이 아니라 웹페이지다. 무엇을 해야 하는지(시험까지 남은 것)가 안 보인다.
- **과제실**: 베이지 문서 패널에 셀렉트 박스, 「진행·제출 확인·전체」 탭, 링크 몇 개가 있다. 과제마다 몇 문제를 풀었는지, 어떤 개념이 필요한지, 제출본이 준비됐는지가 한눈에 안 보인다.
- **강의실**: 한 회차가 약 70단계로 잘게 나뉘어 있고 단계마다 1~2문장을 읽은 뒤 「한 문장으로 말해 볼래요?」를 묻는다 → 대표님 지적 「강의 없이 질문부터」.
- **자료가 흩어져 있다**:
  - 수업 정리 `notes/lessons`(32회차), 교실 단계 `notes/classroom`, 시험 덱 `notes/*-mid*-slides`, 과제 해설 `notes/em-hw*`, 암기 노트 `notes/memo`
  - 오타 팀 문제집(.201, 작업 중)
  - 학생이 「오늘 이 회차를 끝내려면 뭘 보고 뭘 풀지」가 한 묶음으로 묶여 있지 않다.

## 8. 스쿨 메인(로비) — 「오늘 뭘 하면 되는지」가 첫눈에 보이는 복도
### 화면 (아이패드 가로 1040×918 기준)
```
┌ HUD: ⟵대표실  학교 1층 로비            10:42  ⓜ지도  ⚙ ┐
│                                                        │
│  [스앵님 서 있음]   말풍선: 「오늘은 정역학 9/21 이어서   │

│                                                        │
│  ┌문 정역학┐ ┌문 미적2┐ ┌문 공수1┐ ┌문 일물2┐ ┌문 CADD┐   │  ← 복도에 늘어선 진짜 문

│  │▮▮▮▯ 5/8│ │…       │ │…       │ │…       │ │…      │  │    진도 칸(회차) + 페이스 등(초록·노랑·빨강)

└────────────────────────────────────────────────────────┘
```
- **「지금 할 것 1개」**: 스앵님이 직접 말한다. 고르는 순서:
  1. 마감 D-2 이내 과제
  2. 페이스 빨강 과목의 다음 회차
  3. 복습 큐(기억 유지 확률 0.9 미만)
  4. 진도가 가장 낮은 과목

  ▶ 하나로 바로 강의실 그 자리에 들어간다.
- **문패 숫자**: 기존 지표를 그대로 쓴다. 진도·정답·이해·남음은 10/9 「지금 식 유지」. 링 = A+ 준비도, 칸 = 범위 회차(정리된 칸만 채움), 등 = 남은 기간 대비 페이스.
- **비시험 과목(아글·창업)**: 복도 옆 작은 문으로 둔다. 시험 기간엔 접는다.
- **문 누르기**: 문이 열리는 전환 → 그 과목 강의실(9절). 길게 누르면 과목 요약(회차 목록·약한 단원).
- **시험 모드(D-10부터)**: 복도 게시판에 시험 시간표와 과목별 「남은 회차·약한 단원 3개」를 띄운다.
- **폰(세로)**: 스앵님 말풍선 → 「지금 할 것」 → 문을 가로 스크롤 한 줄 → 과제실·자료실 아이콘 → 오늘 줄.

## 9. 강의실 — 「강의 → 예제 → 확인 → 학습지」 한 회차 수업
### 수업 단위 다시 정하기
- **회차**(9/14 수업 하나) = **섹션 4~6개**(지금 s1~s5) = 섹션마다 **판서 단계 여러 개**.
- 질문은 **섹션 끝에 1번**, 회차 끝에 **학습지 한 장**. 단계마다 묻지 않는다.

### 한 회차 흐름
| 순서 | 시간 | 무엇을 | 화면 |
|---|---|---|---|
| 0 입장 | 30초 | 오늘 목표 3줄 + 「지난 시간 이거 했죠」 1분 회상(질문 없이 스앵님이 말로) | 칠판에 목표 |
| 1 섹션 강의 | 섹션당 2~4분 | 스앵님 강의 대본: 왜 배우나 → 개념 → 판서 단계별(쓰면서 말함) → **예제 1개 풀이 시연** → 흔한 실수 → ★교수님이 시험에 낸다고 한 것 | 칠판이 말에 맞춰 써짐, 자막 |
| 2 섹션 확인 | 1분 | 방금 예제를 숫자·조건만 바꾼 **1문제**(선택지 또는 짧은 답). 틀리면 그 판서 단계로 되감아 다시 설명 | 칠판 옆 문제 카드 |
| 3 반복 | — | 다음 섹션 | 위 섹션 칩이 하나씩 채워짐 |
| 4 회차 학습지 | 10~15분 | 학습지(11절 ①) 5문제 | 학습지 화면 |
| 5 마무리 | 30초 | 결과·약한 곳·복습 예약(FSRS) · 「다음은 ○○」 | 로비로 / 다음 회차 |

- 강의 중에는 질문 칸이 잠긴다. 대신 「?」 손들기로 언제든 끼어들 수 있다(지금 기능 유지).
- ⏭ 건너뛰기는 된다. 건너뛴 섹션은 섹션 칩에 「건너뜀」 표시가 남고 진도에 「읽음」으로만 쌓인다. 이해도에는 넣지 않는다.
- 이미 끝낸 회차: 강의를 빼고 바로 학습지·복습으로 간다(「다시 듣기」 아이콘으로 강의를 다시 들을 수 있다).

### 화면 (아이패드 가로)
```
┌ HUD: ⟵복도  정역학 · 9/14 벡터의 두 곱셈   [s1●][s2◐][s3○][s4○][s5○]  ⚙ ┐
│ ┌──────────── 칠판 (60%) ─────────────┐ ┌ 스앵님 (40%) ───────┐ │
│ │ 판서가 말에 맞춰 위→아래로 써짐       │ │ 상반신, 말할 때 팔   │ │
│ │ 예제 풀이도 칠판에 한 줄씩            │ │ 제스처·표정         │ │
│ │                                      │ │ ─────────────────── │ │
│ │                                      │ │ 자막 / 대화 기록     │ │
│ └──────────────────────────────────────┘ └─────────────────────┘ │
│ ⏮  ▶/⏸  ⏭   ───●────── 섹션 진행        ?손들기   🔊   ⋯           │
└──────────────────────────────────────────────────────────────────┘
```
- 확인 문제·학습지일 때는 오른쪽 40%가 **답 칸**(선택지 2×2 / 숫자 / 손글씨)으로 바뀌고 스앵님은 작은 얼굴로 줄어든다.
- 폰(세로): 칠판 위, 아래에 작은 스앵님 얼굴 + 자막 한 줄, 맨 아래 조작줄.
- 학습 방식 3가지(모니터+아이패드·아이패드만·아이패드+공책, `setup.js`)는 그대로 둔다. 「공책」이면 답 칸 대신 「공책에 풀고 답만 고르기」.
- 조작은 아이콘만, 글자는 내용(대본·문제·선택지)에만 쓴다(기존 규칙).

## 10. 강의자료 구성 — 회차마다 「강의안 패키지」 하나
회차 하나 = 파일 하나: `knowledge/lectures/<과목>-<날짜>.json`. 기존 수업 정리(`notes/lessons`)와 교실 단계(`notes/classroom`)는 **원본·근거**로 남기고, 강의실은 이 강의안을 재생한다.

```
회차 강의안
├ meta: 과목 · 날짜 · 주차 · 시험범위 여부 · 교재 쪽 · 교수 슬라이드 쪽
├ goals: 오늘 목표 3줄
├ recap: 지난 회차 회상 대본(3~4문장)
├ sections[] (4~6개)
│   ├ title · 목표 1줄 · ★시험 언급(교수님이 말한 것만, 근거 있을 때만)
│   ├ board[]: 판서 단계 = 기존 교실 단계 id 를 순서대로 참조(새로 그리지 않음)
│   ├ script[]: 대본 문장마다 {말, 어느 판서 단계에서, 표정/몸짓}
│   │      흐름 = 왜 배우나 → 개념(쉬운 말) → 판서 단계별 설명 → 예제 풀이 시연 → 흔한 실수 → 정리 1줄
│   ├ example: 예제 1개(문제·풀이 줄·답) — 수업 판서/교재 예제 우선, 없으면 생성(「생성」 표시)
│   ├ check: 확인 문제 1개(예제 변형, 정답·오답 해설·되감을 판서 단계)
│   └ sources[]: 근거(녹음 몇 분대·판서 사진·슬라이드 쪽)
└ summary: 한 장 요약(암기 카드로도 쓰임)
```
**만드는 규칙**
- 근거 없는 내용은 넣지 않는다. 섹션마다 근거를 붙인다(10/2 「근거」 규칙).
- 수식은 KaTeX로 렌더해 검사하고, 숫자 예제는 파이썬으로 검산한다.
- 그림은 그림 품질 규칙을 지킨다(겹침·깨짐 0).
- 문제는 자기완결이다(필요한 값과 행렬을 문제 안에, `check_q_refs`).
- 말투: 스앵님 해요체, 한 문장 40자 안팎, 「자,」「여기서 중요한 건」 같은 강의 말버릇은 섹션당 1~2번까지만.
- 시험 범위 회차를 먼저 만든다: 32회차 × 섹션 약 180개. 과목별로 나눠 생성 → 아톰 검산 → **오타 내용 검수 GREEN** 뒤 반영.
- 대표님 확인용으로 먼저 1회차(정역학 9/14)를 시범으로 만든다 → 「이 정도 강의면 됐다」를 받은 뒤 전량.

## 11. 학생 학습지 구성 — 4종, 문항 규격 하나
| 종류 | 언제 | 구성 | 출처 |
|---|---|---|---|
| ① 회차 학습지 | 회차 수업 직후 | 5문제: 개념 확인 2 · 예제 변형 2 · 도전 1 | 그 회차 강의안 |
| ② 단원 학습지(시험 대비) | 시험 D-10부터 | 단원별 8~12문제, 교수 강조·과제 유형 우선 | 오타 팀 문제집(.201)과 합침 |
| ③ 과제 연습지 | 과제 풀기 전 | 과제와 같은 유형, 숫자만 바꾼 3~5문제(과제 정답 노출 X) | 과제 + 강의안 |
| ④ 오답·복습 학습지 | 매일 | 틀렸거나 기억 유지 0.9 미만인 문항 자동 묶음 | 기록(FSRS) |

**문항 규격(모든 학습지 공통)**
```
문항 = { id, 과목, 단원, 회차, 종류(개념/계산/서술/그림),
         문제(자기완결, 그림 포함), 답 형식(선택/숫자±오차/식/서술/손글씨),
         정답, 풀이(줄 단위), 힌트 3단(방향 → 첫 줄 → 거의 다),
         흔한 실수(오답 선택지마다 왜 틀렸는지), 연결 강의(강의안 섹션 id → 「다시 듣기」),
         출처(교수 강조/교재/과제 유형/생성), 난이도 1~3 }
```
**학습지 화면**
- 한 문제씩(기본) / 한 장 보기(인쇄형) 전환
- 위: 문제 번호 칩(맞음·틀림·안 풂 색) · 남은 시간
- 가운데: 문제(그림 포함) → 아래: 답 칸(형식별) · 펜 풀이 칸(아이패드)
- 막히면: 힌트 1→2→3 단계, 그래도 막히면 「이 개념 다시 듣기」 → 그 강의 섹션으로 가서 듣고 돌아옴
- 끝: 결과표(문항별 맞음/틀림·걸린 시간·약한 개념) → 오답은 ④로 자동, 약한 개념은 로비 「지금 할 것」 후보로
- 인쇄: 문제 하나는 한 장 안에, 배율 0.9(기존 규칙)
- 서술형은 스앵님 판정(근거 있음·오개념·불충분)을 쓰고, 자동 정답 처리하지 않는다(오타 팀 원칙과 같음).

## 12. 과제실 — 과제 하나 = 「작업대」 하나
### 화면
```
┌ HUD: ⟵복도  과제실                                    ⚙ ┐
│ 마감 순 카드 벽                                           │
│ ┌ 미적2 · 중간과제물(2) 12.1~13.2 37문제 ─────── D-11 ┐  │
│ │ ▮▮▮▮▮▯▯▯▯▯ 14/37 풀이   제출본: 준비 전              │  │
│ │ 필요한 개념: 12.3 내적 ◐ · 12.4 외적 ○ · 13.1 ○       │  │  ← 이해도 색, 누르면 그 강의 섹션
│ │ [풀기] [연습지 ③] [제출본 만들기]                      │  │
│ └────────────────────────────────────────────────────┘  │
│ ┌ 정역학 · Ch5 ── D-3 🔴 ─────────────────────────────┐  │
│ …                                                        │
│ 접힘: 지난 과제(제출 확인됨)                               │
└──────────────────────────────────────────────────────────┘
```
- **카드 상태**: 시작 전 → 푸는 중(n/N) → 제출본 준비됨 → 제출 확인(LMS에서 확인되면 자동). 제출 여부를 묻지 않는다(9/16 규칙).
- **작업대(카드를 열면)**:
  - 왼쪽: 문제 목록(번호·상태·필요 개념)
  - 오른쪽: 문제 풀기 화면(11절 학습지 화면과 같음, 단 정답·풀이는 안 보이고 힌트·코칭만)
  - 위: 마감·범위·원본 링크(LMS 과제 페이지·문제지 PDF)
- **제출본 만들기**: 정역학은 표준 형식(HW-Ch4_제출본_v2), 공수1은 매주 숙제 형식을 따른다. 미리보기 → 대표님 확인 → iCloud 학교 폴더 복사. LMS 제출은 대표님 「올려」 뒤에만.
- **마감 알림**: D-2·D-1에 로비 「지금 할 것」 1순위로 올리고, 대화 첫머리에 알린다(기존 규칙).

## 13. 동결 전(10/9~10/11) 실제로 할 범위
1. 강의실 흐름(9절): 섹션 단위 강의 → 섹션 끝 확인 1문제. 단계마다 묻던 질문 제거.
