# 교실 v2: 강의실 하나 + 칠판에서 스앵님이 직접 가르치는 쌍방향 과외 (2026-10-08)

대표님 10/8 지적 그대로
- 교실 책상은 하나면 된다(내 자리).
- 수업할 때 칠판 탭(2D 창)이 뜨지 말고 **게임 속 칠판에 그대로 뜨고**, 김주영 스앵님이 그 앞에서 강의한다.
- 키보드 단축키로 시점 전환을 자연스럽게 잇는다.
- 교실을 여러 개 만들 필요 없다. **옆 버튼으로 과목을 고르면 그 교실로 바뀐다.**
- 버튼 배치를 다시 한다.
- 지금 학습 구성은 쌍방향 과외가 아니다 → 다시 짠다.
- 학습 방식 세부 설정은 **설정 항목**으로 옮긴다.
- 오타와 역할을 나눠 병렬로 만든다.

## 1. 장면

- 학교 복도의 교실 문 5개 → **「강의실」 문 하나.** 연결 복도·대표실 문은 2단계 그대로 둔다.
- 강의실에는 **큰 칠판, 그 옆 스앵님(3D), 칠판 정면의 내 책상 하나**만 둔다.
- 과목을 바꾸면 방 색·칠판 위 과목명·소품이 바뀐다.
- 앉으면 두 시점이 있다.
  - **칠판 보기:** 수업 내용(글·수식·그림)이 3D 칠판 면 위에 정확히 겹쳐 뜬다. 2D 창이 덮지 않는다.
  - **책상 보기:** 내 공책(펜 캔버스)이 3D 책상 위 공책 면에 겹쳐 뜬다.
- 칠판·공책은 HTML(KaTeX 수식 유지)이다. 앉은 카메라는 고정이라, 3D 칠판·공책 면의 화면 사각형에 맞춰 배치한다. 시점이 이동하는 동안에는 숨기고, 도착하면 띄운다.

## 2. 조작

- **시점:** W/↑ 칠판, S/↓ 책상. 카메라는 지금처럼 0.7초 동안 부드럽게 이동한다. 터치는 쓸어 올리기·내리기(지금 것).
- **수업:** Space·Enter 다음, ← 이전, H 힌트, E 더 쉽게, Q 스앵님께 말하기(입력 칸 포커스), 1~5 과목 바꾸기, Esc 자리에서 일어나기.
- 단축키 안내는 처음 한 번 화면 구석에 아이콘과 함께 보여 준다. 설정에서 다시 볼 수 있다.

| 구역 | 내용 |

## 4. 쌍방향 과외 흐름 (핵심)

스앵님이 칠판 앞에서 한 단계씩 진행한다. 대표님이 매 단계 답해야 다음으로 간다.

1. **설명:** 칠판에 내용을 한 줄씩 쓴다. 스앵님이 말하고(입 움직임·손으로 칠판 가리킴), 대사 바에 같은 말이 뜬다.
2. **확인 질문:** 「그럼 이 식에서 다음에 뭘 해야 할까요?」처럼 스앵님이 먼저 묻는다. 확인 문제가 있으면 선택지로, 없으면 짧은 서술(입력·펜)로 받는다.
3. **판정·되받기:**
   - 맞으면 이유를 한 줄로 짚고 다음 단계로 간다.
   - 틀리면 어디서 틀렸는지 짚고 같은 단계를 더 쉽게 다시 설명한 뒤 비슷한 질문을 한 번 더 한다.
   - 「모르겠어요」면 한 단계 아래 선수 개념으로 내려간다.
   - 서술 답은 서버 코치(`coach`·`work-review`)가 평가한다.
4. **끼어들기:** 대표님은 언제든 Q로 질문할 수 있다. 스앵님은 그 단계 근거 안에서 답하고, 답한 뒤 하던 질문으로 돌아온다.
5. **마무리:** 미션 끝에 혼자 맞힌 것·도움받은 것·다음에 다시 볼 것을 스앵님이 말로 정리한다.

- 기록(정답·도움·서술 평가)은 지금 서버 기록(event·work)을 그대로 쓴다. 준비도 계산은 그대로다.
- 정답·전체 풀이를 먼저 공개하지 않는다(지금 코치 규칙 유지).

## 5. 설정

- 더보기 → **「학습 설정」** 패널: 학습 방식(모니터+아이패드·아이패드만·아이패드+공책), 두 기기 역할, 음성 켜기, 움직임 줄이기, 해상도 자동 조절, 단축키 보기.
- 수업 시작 때 뜨던 고르는 창은 없앤다. 처음에는 기기에 맞춰 기본값을 쓴다(터치 → 아이패드만).

## 6. 역할 분담 (병렬)

- **오타 — 3D·기술(파트 A, 작업 폴더 `otta-classroom`):** space.js·school/world/*·space.css의 3D 부분.
  - 강의실 하나(책상 하나·큰 칠판·스앵님 자리)로 바꾸고, 복도 교실 문 5개를 「강의실」 문 하나로.
  - `space.setSubject(name)`: 방 색·과목명·소품 바꾸기.
  - `space.boardRect()`·`space.deskRect()`: 앉은 시점에서 칠판·공책 면의 화면 사각형. 시점 이동이 끝나거나 창 크기가 바뀌면 `school:viewrect` 이벤트를 낸다.
  - 스앵님 강의 동작: `space.saeng.lecture(on)`(말하기 + 칠판 쪽 몸짓), `space.saeng.point()`.
  - 시점 단축키 W/S/↑/↓와 부드러운 전환.
  - 기존 검사 전부 + 새 검사(사각형이 칠판 면과 맞는지).
- **아톰 — 흐름·UX(파트 B, 이 작업 폴더):** school.js 수업 흐름 → `school/tutor.js` 쌍방향 과외 엔진, 칠판·공책 HTML을 A의 사각형에 배치, 대화 바·HUD 4구역·과목 레일, 수업 단축키(Space·←·H·E·Q·1~5·Esc), 학습 설정 패널.
- **경계:** A는 수업 내용·서버 API를 부르지 않는다. B는 3D 장면을 직접 만지지 않고 A의 함수·이벤트만 쓴다. A가 끝나기 전에는 B가 같은 함수 이름의 임시 구현으로 먼저 개발한다.
- **합치기:** A 브랜치를 B에 병합 → 통합 검사 → 서로 교차 검수 → main.
