# 얼라이브위크 연동 — 출결을 구글 캘린더에 자동 반영

학습앱에서 출결·수업 시각을 기록하면 한양 캘린더(rladkxh1004@hanyang.ac.kr)의 그날 수업 블록이 즉시 바뀐다.

## 반영 규칙

| 앱에서 | 캘린더 블록 |
|---|---|
| 출석 (정시) | 🟦 블루베리 유지 |
| 지각 | 🟡 바나나 |
| 출튀 | 🟠 귤 |
| 결석 | 🔴 토마토 |
| 수업 종료 기록 | 블록 종료 시각을 실제 시각으로 조정 |
| 누적 | 설명란에 `출석n 지각n 출튀n 결석n → 결석환산 e/한도` 갱신. 지각이 N회(기본 3, 과목별 규정 우선) 쌓이면 결석 1회로 환산 표시 |

- 휴강(cancelled) 회차와 캘린더에 없는 과목(사회봉사)은 보내지 않는다.
- 전송은 fire-and-forget — 결과는 캘린더에서 확인.

## 설치 (1회)

1. **캘린더 소유 계정**(rladkxh1004@hanyang.ac.kr)으로 [script.google.com](https://script.google.com) 접속 → 새 프로젝트
2. 저장소의 `aliveweek-webhook.gs` 내용을 붙여넣고 저장
3. **배포 > 새 배포 > 웹 앱** — 실행 계정: **나** / 액세스: **링크가 있는 모든 사용자** → 배포
4. 권한 승인 (캘린더 접근 허용)
5. 발급된 `…/exec` URL 복사 → 학습앱 **설정 > 얼라이브위크 웹훅 URL**에 붙여넣고 저장

확인: URL을 브라우저로 열면 `{"ok":true,"service":"aliveweek-webhook"}`가 떠야 정상.

## 스크립트 수정 후

Apps Script 코드를 고치면 **배포 > 배포 관리 > 수정(연필) > 새 버전**으로 다시 배포해야 반영된다 (URL은 유지됨).
