RED — 출결 집계 누락과 기존 필기 오분류 경로가 있습니다.

1. 제 안은 출결·보충학습·학습완료 판정을 분리하는 것입니다. `attStats`(3285~3298행)는 네 상태만 집계합니다. `vlate` 한 건을 넣으면 지각은 0건이고 출석률 분모만 증가합니다. 여섯 상태를 집계하고 휴강은 제외해야 합니다. 머리행의 지각은 late+vlate로 표시하되, 결석 환산은 과목 규정과 분리하십시오. excused·ghost는 보충 대상이며, 학습 후 복습 대상으로 전환합니다. 출결만으로 완료 처리하면 안 됩니다. 현재도 완료는 `reviewed`를 확인합니다(4467행). XP는 새 회차 생성에 10점, 복습 채점에 5/20점입니다(5781·5851행). 상태 변경·자료 병합에는 추가 지급하지 않습니다.

2. OR은 종류별 보유 여부에만 적용하십시오. 보유·이 기기에서 열기 가능·확인 못 함을 구분해야 합니다. PC에만 있으면 ‘PC 보관·열기 미지원’으로 표시합니다. 목록 조회 실패를 미보유로 바꾸면 안 됩니다. 파일 수는 출처별로 보여주고, 해시 등 동일성 근거 없이 합산하거나 합치지 마십시오. 기존 ‘필기본 올리기’가 `판서`로 저장됐으므로, 이를 전부 칠판 판서로 재해석하는 초안은 RED입니다. 기존 첨부는 ‘필기/판서 미분류’로 보존하고 재분류해야 합니다.

3. `schemaVersion`, 생성시각, `courseId`, 상대경로 기반 식별자, 회차 연결, 출처·접근 가능 여부를 추가하십시오. 공통 자료는 명시적으로 연결한 회차에만 반영합니다. 실제 `학습지_정리.md`와 `학습지_텍스트추출.txt`는 접두만 보면 강의자료로 오분류됩니다. `_과제/2주차_과제_제출용.pdf`는 폴더 문맥이 필요합니다. `과제_1주차_판서.jpg`는 판서 종류에 과제 태그를 붙이십시오. 기존 스캐너는 파일명도 12개까지만 보관하므로 그대로 재사용할 수 없습니다. `_pdfprof` 같은 작업 폴더는 수집에서 제외해야 합니다.

4. 달력 내부 전환을 추천합니다. 390px에서 5열이면 여백 전에도 열당 78px입니다. 전체 진도와 태그를 넣으면 읽기 어렵습니다. 모바일 기본은 선택 주의 요일별 목록으로 하고, 5열 표는 가로 스크롤로 제공하십시오. 과목·일차·출결 약자는 상시 표시하고 상세는 눌러 펼칩니다. 색만으로 출결을 구분하지 않습니다.

5. `planned(c)`(3199~3213행)는 수강 시작일과 개별 `cancelled`를 반영하지 않습니다. 정역학 9/2 OT가 1일차, 9/7이 2일차로 계산됩니다. 공휴일은 빠지지만 개별 휴강은 순번에 남습니다. 제 안은 강의 회차와 개인 수강 시작일을 분리하는 것입니다. OT는 강의 회차에 보존하고 수강 전 출결에서는 제외합니다. 휴강·보강을 반영한 공통 회차 목록으로 순번을 계산해야 합니다.

6. 추가 RED는 고정 분모입니다. `mustHTML`(6004~6006행)은 `/3`, `done===3`이므로 MUST만 늘리면 4종 완료를 오표시합니다. 분모를 동적으로 바꾸십시오. 과제도 현재 주차 노트만 검색하면 다른 주에 작성된 마감 과제가 빠집니다. 위 반례와 PC 조회 실패·중복 자료·390px 화면 검증을 통과하면 GREEN입니다. 공개 배포에 파일명 목록을 포함하는 결정은 별도 확인이 필요합니다.
