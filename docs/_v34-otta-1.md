1. `reviewed`는 채점뿐 아니라 `captureLog`에서도 바뀝니다(5956행). `gradeReview`만 감싸면 체크박스 변경이 누락됩니다. 기존 `review:` 항목은 재생성해도 남으므로 차단 근거로 쓰면 복습 완료 후에도 예습이 막힙니다. 회차 상태를 직접 재계산하십시오. 주 2회는 대상 회차 모두 완료해야 허용합니다. 휴강은 제외하고 결석은 보강 대상으로 분리하십시오. 지난주만 검사하면 전전주 미복습을 우회합니다. 종료된 이전 회차 전체를 권고하며, 기록 누락을 완료로 간주하면 안 됩니다. 채점 원본은 먼저 저장하므로(5863행), 재생성 후에도 저장해야 합니다. `again`도 완료로 잡히는 현재 의미를 명시하십시오.

2. `S.weekly={}`는 과거 완료 이력·수동 항목까지 삭제합니다. 이어서 `ensureWeekly()`를 호출하면 규칙·과제·루틴이 즉시 되살아납니다(4626~4643행). 따라서 “비우기”와 “재생성”은 다른 결과입니다. 권고안은 초기화 대상 주의 항목만 비우고, 주차노트 `tasks`·`weeklyRules`·과거 이력은 보존하는 것입니다. 삭제 대상 건수와 복구안을 제시하고 아토에게 범위를 확인해야 합니다.

3. 8·16주차는 아토가 지정한 기본 시험 주간 표기로 둡니다. 실제 과목 시험은 `exams` 날짜의 주차에 별도 표시하십시오. CADD는 8주차 기본 안내와 10주차 과목 시험을 구분합니다. 시험일과 수업일의 정확한 일치를 요구하면 비수업일 시험이 누락됩니다. 회차가 없다는 이유만으로 휴강으로 단정하지 마십시오.

4. DOM 후처리를 권고합니다. `V32.renderGrid`는 래핑할 수 있습니다. 원본 호출 후 `.v32-grid tbody`의 행 순서와 요일 열로 날짜를 계산하십시오. 휴강·학기 밖 셀에도 날짜를 넣고 중복 삽입을 막으면 됩니다.

5. `justify-content:flex-start`에 첫 책 `margin-inline-start:auto`, 마지막 책 `margin-inline-end:auto`를 권고합니다. 여유 공간에서는 중앙, 넘치면 시작점부터 스크롤됩니다. 모든 책에 자동 여백을 주면 책 사이까지 벌어집니다.

6. 표지 제목 CSS는 `.shelf:not(.spine)`으로 제한하십시오. 책등에도 절대 위치·흰색이 적용되는 충돌을 막아야 합니다. `#cNotes` 교체 후 버튼 연결도 다시 해야 합니다(4267~4268행). `V33.SPEC`의 `pre/post` 순회는 가능하지만 범례는 하드코딩입니다(8089행). 문자열 치환만으로 이모지 제거 완료를 판정하지 마십시오.
