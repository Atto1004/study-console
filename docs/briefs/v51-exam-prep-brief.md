### B. 덱 템플릿 `#quiz` 모드 (v6e 패치)
- `#quiz` 로 열면 문제(type q) 장만 + 시작 장 + 전체 결과 장. 개념·암기 장 생략.
- 저장 키 분리: `mc-slides-<deck>-quiz` (학습 진행 `mc-slides-<deck>` 을 건드리지 않음). `mc-slides-last` 도 쓰지 않는다(이어서 학습 위치 보존).
- 끝 장: 정답/오답/안 푼 3칸 + 「틀린 문제만 다시」(기존 final 재사용).
- 문제가 0개인 덱은 앱이 「문제만」 버튼을 안 보인다(decks.json qN=0).

### C. 시험 범위 문제 덱 (정리노트 v2 → build_slides.py, 자기완결·오버플로 게이트 통과)
우선순위 = 시험 가까운 순 + ★ 언급 밀도.
1. **정역학** `statics-mid-slides`: 파트 = Ch.2 성분·방향여현 / 내적·정사영 / 외적·삼중적 / Ch.3 힘의 종류 / 평형·자유물체도. 각 파트 개념 + 암기·이해 + 기초 3~4(객관식) + 응용 1~2(답 입력). 근거: 9/7·9/9·9/14 정리.md, 9/16 영상정리·교수필기.
2. **일물2** `phys2-mid-slides`: 21 전하·쿨롱 / 22 전기장(불연속·연속) / 23 가우스 / 24 전위(여러 점전하 ★★·증명 3제) / 25 도입. 근거: 9/4·9/9·9/11·9/16·9/18·9/23 정리.md.
3. **공수1** `em1-mid-slides`: 1.1~1.3 분류·변수분리·동차 / 1.4 완전·적분인자 ★★ / 1.5 선형·베르누이 / 2.1 2계 기저·차수축소 / 2.2~2.3 특성방정식·연산자. 근거: 9/4·9/9·9/11·9/16·9/18·9/23 정리.md + 과제 해답.
4. **미적2 벡터** `calc2-vectors-slides`: 12.1 좌표·거리·구면 / 12.2 벡터·표준기저·단위벡터 / 12.3 내적 도입. 근거: 9/10·9/15·9/17·9/22 정리.md + 벡터 정리노트 연습 10문제.
- 문제 출처 원칙: 교재 문제·수업 풀이·교수 언급 문제 우선(지침 §11-7). 없는 것은 같은 유형 변형으로 만들되 숫자는 검산. 정답 하나 확정(객관식은 data-ok 하나).
- 기존 임시 덱은 남긴다(회차 파트 링크 유지). 허브는 문제 덱을 우선 노출.
