## 0. 참고 자료 정정 (RED 1)
- 참고 시트 = 앱스토어 홍보 스크린샷 **42장**(메가 9 · 이투스 수강 12 · MY247 9 · 대성 12, 폰만). 나머지 17장은 아이패드용이라 시트에서 뺐다. 축소 이미지라 **색상값·px·서체는 시각 추정**이며 확정 규격이 아니다.
- r1 §1의 "공통"은 잘못된 일반화였다. 정정:
  - 강조색은 **브랜드 1색**이지 화면의 색이 1개가 아니다(MY247 노랑 순위·다색 시간표, 메가 노랑 별). → 우리: 브랜드 초록 1색 + 콘텐츠 색(과목색)은 허용하되 §2 역할표로 제한.
  - "카드 안 카드 없음"은 관찰이 아니라 **우리의 선택**(메가 QUICK·MY247은 패널 안 카드 있음).
  - 하단 탭 수는 4~5로 갈린다(이투스 4, 메가 5, 대성 5, MY247은 햄버거). → 우리 5는 우리 선택.
  - 행 목록의 단위는 앱마다 다르다(강의·강좌·사람). 우리는 **과목 행**(과목 탭)과 **회차 행**(과목 화면) 둘로 정의.
  - "상단 숫자 요약"도 앱마다 형태가 다르다(3칸 · 원형 · 큰 숫자 1개). 우리는 3칸을 택하되 각 칸의 분모를 §3에 정의.
- 참고에서 실제로 가져오는 것 4가지만: **① 평면 흰 카드 + 연회색 바탕 ② 행별 정보 정렬(썸네일 · 제목 · 메타 · 우측 상태) ③ 작은 배지 1종으로 상태 ④ 화면 상단 요약 숫자**.

### 저장·연동 상태
- 헤더 우측 아이콘 1개 + 짧은 라벨 3상태: `저장됨`(회색) · `저장 안 됨`(초록 점 + 버튼) · `저장 실패`(빨강 텍스트, 다시 시도). **기존 `markSave`는 dirty 2상태뿐**(index.html 3106~) → V44에서 `markSave(state)`를 `"dirty"|"saved"|"failed"` 3상태로 확장(기존 호출 `markSave()`/`markSave(false)`는 dirty/saved로 매핑해 호환), `cloudSave` 의 catch/네트워크 오류에서 `markSave("failed")` 호출 추가, 재시도 = 같은 버튼 = `cloudSave()` 재호출. 실패 뒤 성공하면 saved.
- atom 연동(LMS·캘린더): 각 카드 하단 메타 1줄 `LMS 09-21 08:00 갱신` / `갱신 실패 · 다시`. 기존 `V25.lms` 캐시 시각 사용.
- 이어서 학습 기록이 없을 때 오늘 탭 주버튼 = **「오늘 첫 회차 학습하기」**(오늘 회차 중 덱 있는 첫 회차 `openStudy`), 그것도 없으면 주버튼 없음(할 일 요약이 첫 카드).

## 3. 덱 — 가변 배치·풀이·필기·결과 (RED 4)
- 배치: 본문 `#body`는 **세로 중앙 아님**, 상단 정렬 + 넘치면 스크롤(`.scrollable` 기존 규칙 전체 적용). 보기는 **≥700px `repeat(2,minmax(0,1fr))` 고정 2열, <700px 1열**(auto-fit은 3~4열이 될 수 있어 쓰지 않음).
- 조작부: 상단 = 연속 진행바(파트 안 진행, 시험 언급 장은 핑크 눈금) + `9/89` + 파트명. 하단 = `[이전]` `[힌트]` `[필기]` `[출처 n]` ─ `[다음]`(주버튼 1개). **필기·출처는 위치 그대로**, 서체만 Pretendard.
- 파란 상자 테두리 제거: `.why/.concept/.one` 은 배경 연회색 + 좌측 3px(개념 파랑) 바.
- 문제 장: 즉시 채점(아토 지시) 유지. 정답 → 보기 초록 + 하단 `정답` 배지 + `[다시 풀기]` 텍스트. 오답 → 풀이 판 자동. 주관식 → 답 입력 → 풀이 판 + [맞았어요/틀렸어요].
- 결과 장: 3칸 `정답 · 오답 · 안 푼 문제`, 분모 = 파트 문제 수(건너뜀 제외, 기존 `partScore`). 통과 기준 문구 `기초 전부 정답 + 응용 3문제 중 2문제 이상`처럼 **숫자로**. 아래 `틀린 문제` 목록(문제 번호 · 첫 줄). **주버튼 우선순위(하나만)**: ① 오답 > 0 → `[틀린 문제 복습]` ② 오답 0 · 안 푼 문제 > 0 → `[안 푼 문제 풀기]` ③ 전부 정답 → `[다음 파트]`(마지막 파트면 `[전체 결과]`). 보조 텍스트 버튼: `이 파트 처음으로`. 안 푼 문제가 있으면서 오답도 있으면 ①이 주, `안 푼 문제 n개` 는 보조 텍스트 버튼.

## 4. 탭 목적지·숨은 기능 경로 (RED 5)
- 하단 5탭 = **오늘 · 할 일 · 학습 · 과목 · 설정**. PC 레일 동일 5 + 없음.
- 달력(`v-cal`) = **오늘 탭 헤더 우측 「달력」 텍스트 버튼** → 기존 달력 뷰 그대로(뒤로 = 오늘). 학점·졸업(`v-grade`) = **과목 탭 상단 세그먼트 `과목 | 학점 | 졸업`**. 두 곳 다 URL 해시 유지해 즐겨찾기 가능.
- 즐겨찾기·숨김·편집 = 과목 행 우측 `⋯` 버튼(PC·키보드) **그리고** 길게 누름(폰) 둘 다 → 기존 `bookMenu(cid)` 그대로 호출.
- 개인 공부 = 과목 탭 세그먼트 `학교 | 개인`(기존 `#shelfKind`) 유지.

## 5. 구현 방식 — V32~V43 유지 범위·회귀 (RED 6)
- **전부 유지**. 새 `V44 LAYER`의 **변경 허용 목록(이 밖은 손대지 않음)**: ① CSS 토큰/셸(바탕·카드·헤더·탭·레일) ② `renderShelf` 교체 ③ `renderToday` 중 `#dayBooks` **내부 HTML만** ④ `markSave` 3상태 확장 + `cloudSave` 실패 호출 ⑤ 탭바·레일 항목 목록(5개) + 달력·학점 진입 버튼(기존 `go("cal")`/`go("grade")` 호출, 해시 유지) ⑥ `V43.html` 의 영문 라벨 `RESUME` 제거(구조·삽입 로직은 그대로). 나머지 뷰는 CSS만.
- **보존해야 하는 DOM 구조(V43·V25 의존)**: `#dayBooks`는 지금처럼 `.card > .card-b > #dayBooks` 안에 남긴다 — V43은 `$("#dayBooks").closest(".card").nextSibling` 앞에, V25 타이머도 같은 기준으로 삽입한다(9455·7578). 오늘 탭 카드 순서(오늘 수업 → 이어서 학습 → 타이머 → 할 일 요약 → 컨디션)와 `renderToday`/`renderCourse`/`closeNote` 래핑 호출 체인은 그대로.
- `renderShelf` 교체: `#shelf` 안에 `.book` 대신 `.crow[data-c]` 행을 그리되, **기존 이벤트 블록(짧게=go course · 520ms 길게=bookMenu · contextmenu)을 함수로 빼서 그대로 바인딩**(index.html 3776~3789 이관). `bindRt`·`btnShowHidden`·개인 공부(`renderPersonalShelf`) 분기 보존. `bookHTML`은 삭제하지 않고 미사용.
- `#dayBooks`: id 유지(안에 행을 그림) → V43 삽입 기준·V25 타이머 기준 그대로. `#shelfTiles`·`#courseTbl` 등 다른 id도 유지.
- V38 「학습 준비 중」 문자열 치환 → **V44에서 `V37.cellHTML` 을 data 판정으로 재정의**하지 않고, V38 로직은 그대로 두되 새 회차 행은 .50에서 손댈 때 `data-deck="0|1"` 속성으로 판정하도록 V38을 함께 수정.
- 회귀 검사 목록(스모크에 추가): 과목 열기(클릭) · 길게 누름 메뉴 · 즐겨찾기 토글 · 숨김 보기 · 개인 공부 세그먼트 · 회차별 덱 진입 · 준비 중 비활성 · 이어서 학습 카드(기록 있음/없음/닫기 후 갱신) · 저장 3상태 · 달력·학점 진입 경로 · 390/768/1180 넘침 0 · 다크.
- 순서: **.49** = §1 합격 기준 하네스 → 셸 토큰 → 과목 행 → 오늘 탭 → 회귀. **.50** = 회차 행 · 할 일 단일 목록 · 덱 조작부/결과.
