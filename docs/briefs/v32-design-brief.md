## 2. 아톰 초안

### 2.1 출결 상태 6종
`ATT` 에 `excused:{n:"인정결석",sh:"E"}`, `vlate:{n:"개큰지각",sh:"VL"}` 추가. 색 토큰: absent 빨강(#C7261B 기존) · late 노랑(#D9A400) · excused 분홍(#E0569B) · ghost 보라(#7C3AED) · vlate 주황(#EA7A1A).
- 통계 규칙(제안): 머리행 `(결석/지각)` 의 결석 = absent 만, 지각 = late+vlate. excused·ghost 는 따로 세지 않고 색만. 
- 기존 `status!=="absent"` 필터는 그대로 둔다 → excused(출석 인정)·vlate·ghost 는 학습 완료·복습 큐에 포함. 이게 맞는지 오타 판단 요청. ghost(출튀)는 수업 내용을 다 못 들었는데 복습 큐에 들어가는 게 맞나?

### 2.2 자료 4종
`MUST` 를 4종으로: rec 녹음본(kinds 녹음 + 텍스트 슬롯 rec) · pre 강의자료(kinds 자료 + 슬롯 pre) · note 내 필기본(kinds **필기**[신설] + 슬롯 note) · board 칠판 판서(kinds 판서, 슬롯 없음). 첨부 kind 선택지에 "필기"·"녹음" 추가. 기존 "판서" 첨부는 그대로 판서로 센다(마이그레이션 없음). 「올리기」 kind 고정: note→필기, board→판서.
- 회차 판정 = 기기 로컬(첨부·슬롯) **OR** PC 폴더 인벤토리(아래 2.3). 출처를 점 옆에 작은 글자로(기기/PC).
