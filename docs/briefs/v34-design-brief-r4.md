## 1·2 → 2.5‴ 할 일 초기화 = 앱 안 결재
- 패치는 **실행하지 않고 준비만** 한다. `V34.resetPlan(mon)` = 이번 주 entry에서 `key` 있는 항목(자동) 목록·건수, `key` 없는 항목(수동) 건수, 재생성 후 예상 항목 수(2.1″ 규칙 적용한 dry-run: generateWeekly를 임시 복제 entry에 실행) 계산.
- 할 일 탭 상단에 1회 배너: 「할 일 초기화 — 자동 항목 N건 제거, 수동 M건 보존, 재생성 예상 K건(예습은 복습 완료 과목만). [실행] [나중에]」. **[실행]을 아토가 누르면** 그때 백업 → 제거 → 재생성. 배너는 실행 전까지 매번 뜸(「나중에」는 이번 세션만 숨김).
- 저장 구조: `S.patches.v34a = { mon, at, removed, kept, regenerated, backup:{items:[…원본]} }` **한 객체에 backup 포함**, 이미 있으면 재실행·덮어쓰기 없음(배너도 안 뜸). 되돌리기 `V34.restoreTodo()`(설정 → 패치 노트 카드 버튼) = backup.items를 entry에 복원 후 `S.patches.v34a.restoredAt` 기록(백업은 그대로 둠).

## 3 → 2.8‴ 16주 목록 판정 (수강 상태 반영)
- 주 w의 회차 `ps`, 각 회차 `s=sessionOn(c.id,p.date)`. 분류:
  - `ps.length===0` → 「수업 없음」.
  - 전부 `cancelled`(또는 `holidayOn`) → 「휴강」 회색.
  - 끝난 회차가 하나도 없음 → **미수강 `.fut` 회색**.
  - 끝난 회차 중 **출석한 것**(`status ∉ {absent, excused, ghost}` — 지각·개큰지각은 출석) 이 하나도 없음 → 「결석 · 보강 필요」(경고색, 정리 없음 판정 ✗).
  - 출석한 끝난 회차 있음 + 일부 미종료 → 「진행 중」.
  - 출석한 끝난 회차 있음 + 전부 종료 + `!weekNoteHas` → 「정리 없음」 경고 / `weekNoteHas` → 요약 행.
- 결석 회차가 섞인 주(주 2회 중 1회 결석)는 출석 회차 기준으로 정리 판정하고 「결석 1」 배지 병기.
