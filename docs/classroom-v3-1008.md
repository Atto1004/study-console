# 교실 v3: 강의 → 문제 → 대화, 위·가운데·아래 세 칸 (2026-10-08)

대표님 10/8, v2를 직접 써 보고 지적한 것
1. 게임 모드와 맥(사이트) 화면 모드가 정리가 안 되어 있다.
2. 「재생」을 누르면 선생님이 강의를 해야 한다.
3. 선생님이 말을 걸고 설명하는 구조가 없다. 자막·말풍선·대화창 같은 것이 필요하다.
4. 위쪽에 **게임(3D) ↔ 사이트** 모드 전환을 둔다.
   - 정지·재생은 아래로 옮겨 수업 진행에 맞춘다.
   - **아래 = 채팅으로 소통하며 진행, 가운데 = 내가 문제를 푸는 곳, 위 = 강의 듣는 곳**으로 나눈다.
   - 필요한 것만 남기고 나머지는 뺀다.
   - 수업을 시작하면 진행이 안 된다.

원인(라이브에서 쓰기를 막고 재현): 앉자마자 강의 없이 「방금 내용을 한 문장으로 말해 볼래요?」가 먼저 뜬다. 답하기 전에는 「다음」과 Space가 잠겨서 멈춘 것처럼 보인다. 오른쪽 위 ▶·⏹은 학습 시간 기록(얼라이브위크)인데, 강의 재생 버튼처럼 보인다.

## 1. 화면 — 두 모드, 같은 세 칸

```
┌ 헤더 ─ [게임 | 사이트] 전환 ─────────────── 지도 · 더보기 ┐
│ 위   강의    칠판(수업 내용이 한 문장씩 써짐) + 스앵님 + 자막(말풍선)      │
│ 가운데 문제  확인 질문·선택지·내 답(입력/펜 공책) — 강의가 끝나면 나타남   │
│ 아래  대화   스앵님과 채팅 줄 + 입력 + [⏮ ▶/⏸ ⏭ 진행 3/12] + 힌트       │
└──────────────────────────────────────────────────────────┘
```

- **게임:** 위 칸에 3D 강의실(칠판 + 3D 스앵님)을 그린다. 칠판 면에 수업 내용이, 스앵님 머리 위에 말풍선 자막이 뜬다. 강의실 밖(복도·연결 복도·대표실 문)은 지금처럼 전체 화면 1인칭으로 걷는다.
- **사이트:** 3D를 불러오지 않는다. 위 칸은 2D 칠판 카드와 스앵님 얼굴(웹툰 초상)과 자막이다. 인강 사이트처럼 쓴다.
- 전환은 헤더 아이콘 하나로 하고, 기기마다 기억한다. 기본값은 사이트다(가볍고 빠름). 수업 중에 바꿔도 같은 단계가 이어진다.
- **뺀다:**
  - 시점 아이콘 줄(칠판·공책·질문·도구·일어나기)
  - 오른쪽 세로 묶음
  - 미션 진행·수업 제목 알약 중복
  - 위쪽 학습 기록 띠(▶·⏹·📊)
  - 아래 도구 줄의 근거·보충 → 아래 「⋯」로
- **남긴다:** 과목 레일(왼쪽, 1~5), 지도, 더보기(학습 설정·스킬·공부 종료).

## 2. 강의 재생 (핵심)

- 단계에 들어가면 **스앵님이 바로 강의를 시작**한다. 다시 누를 필요 없다.
- 강의 대본은 그 단계의 `speech`와 칠판 내용을 문장 단위로 나눈 것이다. 문장마다 다음이 함께 일어난다.
  - 칠판에 그 문장을 쓴다.
  - 자막(말풍선)에 그 문장을 띄운다.
  - 스앵님이 말한다. 게임에서는 입·몸짓, 사이트에서는 초상 입 모양.
  - 음성이 켜져 있으면 읽어 준다. 꺼져 있으면 글자 수에 맞춘 시간만큼 보여 준다.
- 아래 ▶/⏸는 **강의**를 멈추고 다시 튼다. Space와 같다.
- ⏮는 이 단계 강의를 처음부터, ⏭는 다음 문장(끝이면 다음 단계)으로 간다.
- 학습 시간 기록(얼라이브위크)은 강의 ▶/⏸를 따라간다. 따로 버튼을 두지 않는다. 공부 종료는 더보기로 간다.

## 3. 강의 뒤 → 문제 → 대화

- **개념 단계:** 강의가 끝나면 스앵님이 아래 채팅으로 확인 질문을 한다. 가운데 칸에 답 칸이 열린다(학습 방식대로 입력 또는 펜). 답하면 판정해서 되받는다(v2 그대로).
  - **답하지 않고 ⏭로 넘어갈 수 있다.** 이때는 「읽음」으로만 기록하고 이해 판정은 하지 않는다. 진행이 막히지 않게 하기 위해서다.
- **문제 단계:** 강의에서 문제를 읽어 준 뒤 가운데 칸에 선택지·풀이 칸이 열린다. 답해야 다음으로 간다(지금 그대로). 막히면 힌트와 「더 쉽게」를 쓴다.
- **채팅:** 스앵님 대사와 내 답·질문이 아래 채팅 줄에 대화로 쌓인다. 「?」로 끝나는 끼어들기 질문은 v2 그대로다.

## 4. 역할 분담 (병렬)

- **오타 — 파트 A3(3D·기술, 작업 폴더 `otta-v3`):** space.js·school/world/*·space.css 3D 부분.
  - **무대 안에 그리기:** `space.mount(stageEl | null)`. 게임 모드 착석이면 3D 캔버스를 위 칸 요소 크기에 맞춰 그린다. null이면 걷기용 전체 화면.
  - 앉은 시점 카메라를 위 칸 비율에 맞춰 칠판과 스앵님이 함께 보이게 잡는다. 공책 시점은 쓰지 않는다(공책은 가운데 칸 2D).
  - `space.boardRect()`는 무대 안 칠판 면이다(지금 계약 유지). `space.saeng.headPoint()`는 말풍선 자리({x,y} 화면 px)이며, 이동·크기 변경 때 `school:viewrect`에 `head`도 넣는다.
  - `space.saeng.lecture(on)`·`point()`는 지금 그대로. 사이트 모드에서는 3D를 아예 불러오지 않아야 한다.
  - 기존 검사와 새 검사(무대 크기별 칠판 면·머리 위치 일치).
- **아톰 — 파트 B3(흐름·화면, 이 작업 폴더):** 세 칸 배치·모드 전환, `school/lecture.js`(강의 재생기: 대본·자막·칠판 문장 쓰기·말하기·▶/⏸/⏮/⏭·음성), 채팅 줄·가운데 칸, 뺄 것 빼기, 「진행 안 됨」 해결(⏭ 넘기기 허용), 학습 시간 기록을 강의 재생에 연결.
- **경계:** A는 수업 내용·서버 API를 부르지 않는다. B는 3D 장면을 직접 만지지 않는다. A가 끝나기 전에는 B가 사이트 모드로 먼저 완성한다.
- **합치기:** 오타가 GREEN이면 바로 main(대표님 10/8 규칙).
