# 학습앱 피그마 지시서 (아톰 주도, 2026-10-07)

원본 계획: `~/.claude/plans/1234-adaptive-stearns.md` (대표님 승인 10/7).
피그마는 **모양만** 바꾼다. 기능·데이터·배치 순서·동작은 코드가 정하고, 피그마 결과는 `school/skin.css` 토큰과 이미지 슬롯 교체로만 들어간다.

## 기준
- 화면 1040×918 (아이패드 가로). 폰은 이번 범위 밖.
- 도트 금지. 대표실 도트 스킨과 섞지 않는다.
- 방향: 애플식 단순한 면 + 게임처럼 "장소에 들어간다"는 감각. 장식은 진행·성취를 보여줄 때만.
- 글꼴: 본문 고딕 한 벌(Pretendard 계열). 숫자는 같은 글꼴의 고정폭 숫자.
- 설명 글은 (i) 안으로. 버튼 글자는 동사 하나.

## 지표 표시 규칙 (F2·F6)
- A+ 준비도 = 이해도 50 + 정답률 30 + 진도율 20 (0~100). 링 하나, 숫자 크게.
- 남은 기간 대비 진도: 트랙 위에 오늘 위치와 진도 깃발. 깃발이 오늘보다 앞이면 초록, 0.8~1배 노랑, 그 밑 빨강.
- XP·레벨·하트·연속일 없음.

## 스앵님
- 그림 교체는 피그마가 아니라 이미지 생성으로 한다(피그마는 그림 생성에 약하고 호출을 많이 씀).
