   고칠 방법: `.bl.dim`의 글자 흐림을 제거하고 번호·테두리로 지난 단계를 구별하십시오. 색은 강조선에 쓰고 작은 설명은 흰색으로 통일하십시오. 식 상자 배경의 흰색 혼합도 줄이십시오.

## GREEN

- A: 초록 바탕·흰 활자·민트 식 상자·그림 캡션·오른쪽 강사로 레퍼런스의 구성이 전달됩니다. 손글씨 v2로 돌아간 모습은 아닙니다. 다만 `.slide`에는 미세 노이즈가 남아 있어 ‘질감 없음’이라는 설명과는 다릅니다.
- B: CSS의 빨강→산호, 파랑→하늘, 초록→연두, 분홍→분홍 매핑은 색 계열을 보존합니다. 전체 SVG의 의미 보존은 확인 못 했습니다.
- C: 1040px에서는 강사와 판서 열이 분리되어 직접 겹치지 않습니다. 폰에서 전신을 숨긴 판단도 적절합니다.
- D: 목차의 순서와 문제 선택지의 위계는 분명합니다. 식 번호도 첨부 화면에서는 식과 겹치지 않습니다.
