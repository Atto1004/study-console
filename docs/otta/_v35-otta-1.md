**RED.** 저장·재실행과 기존 데이터 보존에 결함이 있습니다.

1. `changed=false`면 완료 플래그를 저장하지 않습니다. 기존 값이 모두 찬 상태에서는 새로고침마다 재실행됩니다. 과목이 없을 때도 같으며, 메모리에서는 완료 처리돼 이후 과목 추가 시 건너뜁니다.
2. `exam/tasks/links`가 배열이 아니면 기존 값을 `[]`로 덮어씁니다. 비배열 데이터가 있으면 손실됩니다. 자동 초기화 대신 검증·변환이 필요합니다.
3. 완료 플래그를 먼저 세워 `persist()`가 동기 예외를 내면 저장 실패 상태로 재시도가 차단됩니다. 빈 `catch`가 실패도 숨깁니다.
4. 기존 `boot()` 호출 뒤 이 레이어가 실행되면 시드는 적용되지 않습니다. 래퍼 등록만 하고 호출하지 않습니다. 실제 호출 위치는 제공 코드로 확인 못 했습니다.
